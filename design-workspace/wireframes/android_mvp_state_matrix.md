# 안드로이드 MVP 상태 매트릭스

| 상태 | 조건 | 사용자에게 보여줄 것 | 허용 액션 |
| --- | --- | --- | --- |
| idle | 앱 진입 직후 | 시작 안내, 지원 종 목록 | 녹음 시작 |
| recording | 5초 녹음 중 | 타이머, 간단 자세 안내 | 취소 |
| quality_pass | 최소 품질 기준 통과 | 분석 가능 안내 | 분석 시작, 다시 녹음 |
| quality_retry | 입력 약함 또는 소음 큼 | 재녹음 팁 | 다시 녹음, 그래도 분석 |
| no_cicada | 매미 소리 없음 | 매미 소리를 찾지 못했다는 안내 | 다시 녹음 |
| analyzing | 특징 추출/분류 중 | 로딩 문구 | 대기 |
| result_high | top-1 확신 높음 | 1순위 중심 결과 | 다시 녹음, 상세 보기 |
| result_mid | top-1 가능하지만 애매 | top-3 후보와 주의 문구 | 다시 녹음, 상세 보기 |
| result_low | 불확실 또는 혼합 가능 | 보류 안내와 재녹음 가이드 | 다시 녹음, 후보만 보기 |
