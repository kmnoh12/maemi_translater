# 1차 UX 카피 초안

## 홈

- 제목: `매미 소리로 종을 추정해 볼까요?`
- 설명: `5초만 녹음하면 가장 가능성 높은 종을 보여드려요.`
- 버튼: `녹음 시작`

## 녹음 중

- 안내: `휴대폰을 나무 쪽으로 향하고 5초만 기다려 주세요.`
- 보조: `자동으로 끝나요`

## 음질 통과

- 제목: `분석할 준비가 됐어요`
- 설명: `매미 소리 특징이 충분히 들려요.`
- 버튼: `분석 시작`

## 음질 재시도 권장

- 제목: `이번 녹음은 조금 아쉬워요`
- 설명: `소리가 작거나 주변 소음이 커서 결과가 불안정할 수 있어요.`
- 팁:
  - `나무에 더 가까이 가 보세요`
  - `차량 소음이 적은 곳에서 다시 시도해 보세요`
- 버튼: `다시 녹음`

## 매미 소리 없음

- 제목: `매미 소리를 찾지 못했어요`
- 설명: `주변이 너무 조용했거나 다른 소리가 더 크게 들렸을 수 있어요.`
- 버튼: `다시 녹음`

## 분석 중

- 제목: `매미 소리를 분석하고 있어요`
- 설명: `잠시만 기다려 주세요`

## 결과 확신 높음

- 제목: `가장 가능성 높은 종은 {종명}`
- 설명: `이번 녹음에서는 이 종의 특징이 가장 뚜렷하게 들렸어요.`
- 버튼:
  - `종 설명 보기`
  - `다시 녹음`

## 결과 확신 낮음

- 제목: `이번 녹음만으로는 확실하지 않아요`
- 설명: `여러 매미가 함께 울었거나 주변 소음이 컸을 수 있어요.`
- 팁:
  - `나무에 2~5m 정도 더 가까이 가기`
  - `5초 동안 흔들리지 않게 녹음하기`
  - `자동차 소음이 적을 때 다시 시도하기`
- 버튼:
  - `후보 보기`
  - `다시 녹음`
