# 안드로이드 MVP 텍스트 와이어프레임

## 1. 홈

- 상단 제목: `매미 소리로 종 추정하기`
- 보조 문구: `5초 동안 녹음한 뒤 가장 가능성 높은 종을 알려드려요.`
- 주요 버튼: `녹음 시작`
- 보조 링크:
  - `어떻게 녹음하면 잘 되나요?`
  - `지원하는 종 보기`

## 2. 녹음 중

- 큰 타이머: `00:05 -> 00:00`
- 상태 문구: `조용한 곳에서 휴대폰을 나무 쪽으로 향해 주세요.`
- 보조 문구: `자동으로 끝나요`
- 버튼:
  - `취소`

## 3. 음질 점검 결과

- 상태 A: 통과
  - 제목: `분석할 준비가 됐어요`
  - 버튼: `분석 시작`
- 상태 B: 재녹음 권장
  - 제목: `소리가 너무 작거나 소음이 커요`
  - 안내:
    - `나무에 조금 더 가까이 가 보세요`
    - `바람과 차량 소음이 적을 때 다시 시도해 보세요`
  - 버튼:
    - `다시 녹음`
    - `그래도 분석`

## 4. 분석 중

- 로딩 상태 문구: `매미 소리 특징을 확인하고 있어요`
- 보조 문구: `잠시만 기다려 주세요`

## 5. 결과 화면

- 제목: `가장 가능성 높은 종`
- 대표 카드:
  - 종명
  - 간단 설명
  - 신뢰도 배지: `확신 높음 / 확신 보통 / 확신 낮음`
- 후보 목록:
  - `1순위`
  - `2순위`
  - `3순위`
- 하단 행동:
  - `다시 녹음`
  - `종 설명 보기`

## 6. 저확신 재녹음 유도

- 제목: `이번 녹음만으로는 확실하지 않아요`
- 설명:
  - `여러 매미가 함께 울었거나 주변 소음이 컸을 수 있어요.`
- 체크리스트:
  - `나무에 2~5m 정도 더 가까이 가기`
  - `5초 동안 흔들리지 않게 녹음하기`
  - `자동차 소음이 적을 때 다시 시도하기`
- 버튼:
  - `다시 녹음`
  - `후보만 보기`

## 7. 종 설명 상세

- 종명 + 대표 특징
- 귀로 들을 때 포인트
- 자주 들리는 장소와 시기
- 비슷한 종과의 차이
- 버튼:
  - `이 종으로 다시 비교하기`
  - `새로 녹음하기`
