# 안드로이드 우선 1차 앱 UX 브리프

## 제품 원칙

- 빠른 정답보다 신뢰 가능한 안내를 우선한다.
- 확신이 낮을 때는 답을 보류한다.
- 사용자가 다시 녹음하면 성능이 좋아질 수 있도록 행동 가이드를 준다.

## 1차 화면 목록

1. 홈
2. 녹음 중
3. 음질 점검 결과
4. 분석 중
5. 결과 화면
6. 저확신 재녹음 유도
7. 종 설명 상세

## 핵심 사용자 흐름

1. 사용자가 녹음을 시작한다.
2. 앱이 5초 동안 녹음한다.
3. 음질과 매미 소리 존재 여부를 먼저 점검한다.
4. 분석 가능하면 종 분류를 수행한다.
5. 결과 화면에서 가장 가능성 높은 종과 다음 후보를 보여준다.
6. 확신이 낮으면 재녹음을 권한다.

## 결과 화면 정책

- 단정 문구 금지
- 함께 보여줄 정보:
  - 가장 가능성 높은 종
  - 다음 후보
  - 확신도 낮음 여부
  - 다시 녹음 팁

## 저확신일 때 보여줄 기본 가이드

- 나무에 더 가까이 가서 5초 다시 녹음해 주세요.
- 바람이 강하거나 자동차 소음이 적은 위치에서 시도해 주세요.
- 여러 매미가 동시에 우는 경우 결과가 불안정할 수 있어요.

## LLM 활용 범위

- 사용자 흐름 정리
- 상태별 문구 초안
- 접근성 문구 초안
- 사용성 테스트 질문 초안

## LLM 비활용 범위

- 생물학적 사실 판정
- 저작권 판단
- 모델 성능 보증
