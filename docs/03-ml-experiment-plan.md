# 머신러닝 실험 계획

## 목표

- 깨끗한 샘플에서만 맞는 모델이 아니라, 야외 녹음에서도 버티는 기준선을 만든다.

## 실험 순서

1. `매미 소리 존재 여부 판단`
2. `3종 분류`
3. `불명/혼합 처리`
4. `5종 확장 여부 판단`

## 모델 비교 순서

1. 신호처리 + 전통 특징 + 경량 분류기
2. 사전학습 오디오 임베딩 + 경량 분류기
3. 소형 스펙트로그램 CNN

## 권장 기본 노선

- 1차 본선 모델은 `사전학습 오디오 임베딩 + 경량 분류기`
- 이유:
  - 적은 데이터에서도 출발점이 좋다.
  - 온디바이스 배포로 이어가기 쉽다.
  - 실패 시 특징 기반 기준선과 비교가 쉽다.

## 전처리 기준

- 사용자 녹음 길이: `5초`
- 내부 분석 창: `3초 슬라이딩`
- 포함할 처리:
  - 리샘플링
  - 볼륨 정규화
  - 무음 구간 완화
  - 클리핑 탐지

## 평가 분할

- 파일 랜덤 분할 금지
- 아래 홀드아웃을 기본으로 한다.
  - `세션 홀드아웃`
  - `장소 홀드아웃`
  - `기기 홀드아웃`

## 핵심 지표

- `macro F1`
- `species recall`
- `confusion matrix`
- `top-1 accuracy`
- `top-3 accuracy`
- `low-confidence abstention precision`

## 실패 판정 규칙

- 실험실셋은 좋지만 장소 홀드아웃에서 급락하면 데이터 전략부터 수정한다.
- 특정 종 재현율이 지속적으로 낮으면 3종 범위 자체를 재검토한다.
- `no_cicada_detected`와 `unknown`을 전혀 다루지 못하면 앱 적용을 보류한다.
