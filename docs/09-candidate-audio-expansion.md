# 후보 음원 확장 규칙

## 목적

- 공개 시드 9개로는 학습이 아니라 파이프라인 점검만 가능하다.
- 따라서 iNaturalist API를 통해 종별 후보 음원 매니페스트를 더 넓게 만든다.

## 확장 전략

- 1순위: 대한민국 관찰 + 라이선스 명시 + 사운드 포함
- 2순위: 주변 국가 포함 공개 라이선스 사운드
- 3순위: 라이선스 없는 항목은 후보로만 기록하고 다운로드 제외

## 현재 자동화 범위

- `참매미`, `말매미`, `유지매미`, `애매미`, `쓰름매미`, `털매미`
- `늦털매미`는 학명/동의어 확인이 더 필요해서 자동화 대상에서 보류

## 산출물

- 후보 매니페스트 CSV
- 다운로드 가능한 공개 음원만 분리한 CSV
- 종별 음원 수 요약 리포트

## 주의

- 후보 매니페스트가 곧 정답셋은 아니다.
- `needs_id`나 라벨 근거 약한 관찰은 본 학습셋으로 바로 쓰지 않는다.
