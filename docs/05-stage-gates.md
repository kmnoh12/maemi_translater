# 단계별 게이트

## 0단계: 로컬 준비

- 목표: 이 PC에서 반복 가능한 작업 환경과 폴더 규칙을 확정한다.
- 완료 조건:
  - Python 기준 버전이 정해짐
  - 오디오 처리 도구 설치 경로가 정해짐
  - 메타데이터 포맷이 고정됨
  - 저장 규칙이 문서화됨

## 1단계: 데이터 수집 시작

- 목표: 3종 MVP용 1차 원본 세션 확보
- 완료 조건:
  - 종당 최소 `30~50 세션`
  - 검수 규칙 운영 시작
  - 메타데이터 누락률 낮음

## 2단계: 학습 기준선

- 목표: 존재 여부 판단과 3종 분류 기준선 확보
- 완료 조건:
  - 세션 홀드아웃 confusion matrix 작성
  - 실패 패턴 기록
  - 저확신 보류 규칙 초안 작성

## 3단계: 앱 UX 초안

- 목표: 결과 표현과 재녹음 유도 방식을 확정
- 완료 조건:
  - 화면 목록 확정
  - 사용자 흐름 확정
  - 카피 초안 확정

## 4단계: 온디바이스 타당성 점검

- 목표: 모바일 후보 모델을 좁힌다.
- 완료 조건:
  - 모델 크기 추정
  - 추론 지연 측정 계획
  - 배터리/발열 체크 항목 정리
