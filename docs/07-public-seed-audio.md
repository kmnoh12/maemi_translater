# 공개 시드 음원 운영 규칙

## 목적

- 완전한 학습셋을 대신하려는 용도가 아니다.
- 로컬 파이프라인 점검, 포맷 검증, 메타데이터 구조 검증, 기준선 실험용 시드 데이터로 쓴다.

## 원칙

- 저작권과 라이선스가 명시된 출처에서만 가져온다.
- `license_code`가 비어 있으면 자동 다운로드 대상에서 제외한다.
- `public_seed_manifest.csv`에 관찰 ID, 음원 ID, 라이선스, 출처 URL을 남긴다.
- 원본은 그대로 저장하고, 파생 wav 파일은 별도 폴더에 둔다.

## 현재 출처

- iNaturalist 공개 관찰 음원
- 기준: 대한민국 관찰 우선, 명시 라이선스 우선

## 주의

- `cc-by-nc`, `cc-by-nc-sa` 등은 비상업적 조건이 포함될 수 있다.
- 상용 앱 배포를 고려하면 나중에 라이선스 재정리가 반드시 필요하다.
- 라벨이 있다고 해서 정답셋 품질이 보장되는 것은 아니다.

## 지금 확보한 시드 음원의 의미

- `참매미`, `말매미`, `유지매미`에 대해 포맷이 다른 실제 공개 파일을 모아 둔다.
- 포맷은 `wav`, `m4a`가 섞여 있어 `ffmpeg` 정규화 검증에 도움이 된다.

## 다음 단계

1. 공개 시드로 다운로드/정규화/메타데이터 흐름을 검증한다.
2. 현장 직접 수집 데이터가 쌓이면 공개 시드와 분리해 관리한다.
3. 본 학습셋은 `confirmed`와 충분한 근거가 있는 데이터 위주로 다시 만든다.
